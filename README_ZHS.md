纯客户端 Fabric mod（**Minecraft 1.21.4**），辅助 **Hypixel Zombies** 小游戏。它只读取你的客户端本就收到的数据（聊天、计分板、标题、世界音效、实体元数据），不做任何服务端改动。

## 功能总览

### 波次计时
- 当前回合每一波的出生秒数表，并高亮下一波。
- 按地图可选开启出生音效提醒。末波会响起两种提示：怪物刷出前 3-2-1 预警倒计时，怪物刷出瞬间再响一声末波刷新音效。
- 「外星游乐园」首领波颜色预警。

### 全局概览 HUD
- 三行六列：`回合` / `首领` / `道具`。一眼看清**当前回合及其后五个回合**里哪些会刷首领、哪些会刷道具。
- 当前回合那一列整列绿色且恒在最左；每进一个新回合，整块向左滚动一列。
- 回合行白色、首领行红色、道具行蓝色、行标题金色；每个格子都是带中括号的回合号（`[XX]`，三位数 `[100]` 也保留括号）。
- 首领行与道具行都读共享数据表（按地图、按难度的首领回合，以及道具规律）。本局即使还没观测到任何道具，整张表也已画好。超过该图通关回合的格子留空：穷途末路 / 坏血之宫 / 监狱风云 30，外星游乐园 105。

### 强化道具
- 三条冗余通道检测道具：盔甲架扫描、实体元数据、聊天激活。
- 首次观测后锁定地图道具规律，预测刷新回合。
- 掉落与拾取提醒。屏幕计时器显示道具已生效时长与下一次刷新倒计时。

### 队伍统计
- 计分板风格 HUD（默认左上角）：每位队友的血量、状态（战斗中 / 倒地 / 死亡 / 退出）、击杀、倒地、死亡与金币。
- 数据缓存到本地文件，快速重进后可恢复。

### 常驻计时 HUD
- 整局游戏时长与本回合用时。游戏结束（通关或团灭）时冻结显示值。

### 回合记录（RKPM）
- 每回合耗时与击杀总数，回合结束在聊天中总结，含 **RKPM**（分均击杀 = 净击杀 × 60 / 回合秒数）。点击消息即可复制。

### 玩家战绩查询
- 配置 Hypixel API Key 后，可按玩家名或 UUID 查询任意玩家，或每回合自动查询当前队友的 Zombies 战绩。
- **局内查询**是**一张平铺概览**，没有可展开层级，从上往下读即可：
    - 账号信息下面是八个**四图累计**：`累计生存`、`累计胜利`、`累计击杀`、`累计救援`、`累计倒地`、`累计死亡`、`累计修窗`、`累计开门`。每一项都是四张地图的**普通+困难+RIP 三档之和**。不含各图自己的「综合」档，否则同一批局会被算两遍。
    - 最后两行是派生项：**`最速通关`**（用时最短的那张图那个难度）与 **`擅长地图`**——只显示**地图-难度**。背后按三项加权选出：**通关次数最多（主）**、**击杀僵尸最多（次）**、**平均通关用时最短（最次）**，权重 3:2:1。三项都是**该图各难度相加之后**再比。外星游乐园只有普通一档，加起来就是它自己。平均用时的分母是**该图实际取到时长的难度个数**：只通关过一个难度就除以 1，不会因为凑不满 3 档而被压低。
    - 这两行有**双重前提**：该图最佳回合达到它的通关回合，**且**该图该难度至少赢过 1 次。通关回合分别是：穷途末路 30、坏血之宫 30、监狱风云 30、外星游乐园 105。所以「到了 30 回合但团灭」不会被算成通关。两条都不满足时这两行显示 `-`。
    - **每一行都固定出现，缺的格子画 `-`**。某一项在四张地图里一张都没有 → 那一行（四个地图格子与「综合」）全是 `-`；只是某一张图没有 → 那张图记 `0` 并照常参与求和。行不再因为没数据而消失，前后两行的位置永远固定。
- **所有文字都上了色**：标题金、字段名灰、**数据一律白**；难度名按档上色——综合橙、普通绿、困难红、安息深红。自由查询的累计数据与地图明细里，**四个地图名与「综合」也上橙色**。
- **局内队友列表没有 ◀ / ▶，也没有自动轮换**。直接点列表里那个玩家切换即可，不会自己跳。选中那条的底板会完整包住两行文字。
- **自由查询**（自己输名字查）保留**可折叠的树**。最上面先平铺「玩家概览」（显示名/等级/Karma/经验/三个时间），下面才是 `[+] 综合统计` / `[+] 时间统计` / `[+] 敌人击杀` 三个父项，就这个次序。**父项后面不带任何汇总数字**，点一下才展开。展开「综合统计」后，第一项是 **`[-] 累计数据`**，八行与局内查询那八个累计项**逐字同源**。再往下是**四张地图各一个节点**（玩家没玩过的图也会列出来），每张图**固定九行**：`最佳回合` 排第一，其后依次是 `存活回合`、`通关次数`、`击杀僵尸`、`救人次数`、`倒地次数`、`死亡次数`、`修窗次数`、`开门次数`。取不到的项该行画 `-`，**不会把那一行抽掉**——位置固定，你才记得住哪一行在哪。
- **「累计数据」的八行是「合并大行」**。行名在左侧居中，数据在右侧、整体贴右缘。**数据不超过 4 个就是一行，超过 4 个才排两行**，两行左缘对齐。所以只有这八行会排两行，四张地图的明细仍是原来的一行（档位固定、数字短，没有换行的可能）。数字再长也不会折行挤乱。**四个地图名与「综合」是橙色**，数字保持白；地图明细里的难度名仍按档上色：普通绿、困难红、安息深红、综合橙，而「综合」排在最后。左侧的树线是**连续画出来的线**，不是 `├─` 这类字符，所以不会一格一断。鼠标悬停或选中时**整块两行一起亮**。展开状态按你查的那个名字记住。
- **「时间统计」里每个回合固定列十项**。格式为**`地图-难度`**（例如 `穷途末路-安息`），**整条按该难度同色**：`穷途末路-普通` 整条绿、`…-困难` 整条红、`…-安息` 整条深红。右侧时间保持白。顺序固定为：穷途末路 普通/困难/安息 → 坏血之宫 普通/困难/安息 → 外星游乐园 普通 → 监狱风云 普通/困难/安息。外星游乐园没有困难与安息记录，所以只有普通一项。原先那个跨图合计的「全局」行已移除。
- 中文客户端里**监狱这张图叫「监狱风云」**（英文仍是 `Prison`），配置界面与查询界面写法一致。

### 抽奖统计 HUD
- 只统计**你自己**的幸运箱抽奖，并排成一张表：`总抽取次数`，下面每行一个奖励——小图标、抽到几次、**第几次抽到的**（写 `4,6` 就表示本局第 4 次和第 6 次抽奖抽到的这个）。
- **默认就显示**：新装或删掉配置后进游戏，这块 HUD 会直接在屏幕上。一局还没开箱时显示 `总抽取次数 0` 与一张空表。
- 共追踪 11 种奖励（Zombies 各武器与两项技能）。不在这一表内的奖励（例如金币）不计入；奖励名与表里对不上的也不会猜着算，直接跳过。
- 开一次箱子会有两条消息（抽中 + 领取），它们属于同一次抽奖，所以总次数只涨 1，不是 2。
- 计数**只对当前这一局有效**：开新局即归零。但**误退出再重进同一局不会丢**——计数会临时写在缓存文件里，重进时恢复。
- **抽了箱子却不涨数，值得反馈**：本版已移除全部诊断日志，mod 不会再自己报告原因。请把游戏里那条幸运箱原文发出来，好据此校准文案。

### 聊天过滤与侧边栏增强
- 隐藏嘈杂的聊天行：金币获得、窗户修复、击中目标、幸运箱、开启区域、玩家进出。
- 清理 Hypixel 侧边栏：剥离空行与玩家行；开启计时 HUD 时移除原生时间行。
- **可拖动计分板**（默认关，与其余 HUD 元素一致，唯一例外是抽奖统计 HUD）：在 HUD 编辑器里可拖动、缩放原生侧边栏。行内容仍是同一套清理结果，只是位置与大小归你。把它**关掉即整条隐藏**，实用 HUD 总开关关也会一并隐藏。原单独的「隐藏原生计分板」选项已移除。
- 编辑器的计分板样张恒为**固定样张**。它只把**真在画布上且已启用**的「队伍统计 HUD」「计时 HUD」算进去：勾掉「显示」或把它们拖回组件库，样张立刻展开回完整侧边栏（玩家行、完整时间行都回来），不用等保存。从主菜单打开与局内打开看到的是同一副样子。

### 实体 ESP
- 为队友（战斗中**红色**、倒地**黄色**）、僵尸等敌对生物（**绿色**）、首领（**橙色**）与已刷新道具（**白色**）绘制线框。
- 每种 ESP 均有独立开关与**渲染机制**：**常规**（尊重遮挡，墙后隐藏）或**穿墙**（可穿透障碍物显示）。
- 全局**穿墙渲染距离**滑条（5-200 格）控制穿墙效果的最大生效范围。

### 僵尸血条
- 每个敌对生物头顶的世界空间血条（`[#######------] 12/20HP`），按剩余血量变色。数字保留一位小数（`19.6/20`），与伤害飘字同一口径——飘在身上的数字和头顶血条永远对得上。
- **首领另有配色**：血量高于 75% 为紫色，随后依次转黄、橙、红。血条也整体抬高，避开首领自带的血条名字。普通怪仍是绿 / 黄 / 红三档。

### AA 自动指挥
- 在「外星游乐园」：回合指挥 HUD（巨人刷新 / 长者刷新 / 难度 / 推荐点位），外加每回合开始时的自动聊天播报。

### 电击棒充能冷却 HUD
- 在「外星游乐园」：4 槽 HUD 追踪每根电击棒 20 秒冷却，按剩余时间变色。

### 效果状态 HUD
- 局内会把原版右上角的状态效果图标格换成一个文字列表。每个效果占两行：首行 `图标 效果名 等级`，次行剩余时长（`M:SS`，无限显示 `∞`，剩余 3 秒及以内转红）。
- 最快结束的排在最上；没有任何效果时整块不显示。等级用罗马数字，I 级按原版习惯省略不写。

### QoL 工具箱
- **平滑缩放**：按键触发，滚轮热调、缓动曲线、灵敏度补偿。
- **永久潜行** / **永久疾跑** / **伽马覆写**（强制亮度）。
- **自由视角**：相机脱离身体自由观察。
- **隐藏附近玩家**：1.4 格内的玩家不渲染。
- **隐藏原生 Boss 血条**。原生计分板改由上面那个可拖动计分板自己的开关控制。
- **仅右键开火**：屏蔽非开火右键交互。
- **移除所有粒子**与**无火焰覆盖**。
- **CPS 统计**：每秒左右键点击数。
- **伤害飘字**：掉血冒红字、回血冒绿字，只显示数字——秒杀也是一个普通数字。常规档墙后看不见，穿墙档在障碍物后面也能看见，最远到「总穿墙渲染距离」。

### HUD 编辑器
- 在配置界面中单独拖动、缩放、开关每个 HUD 元素。
- **布局与分辨率无关，而且位置就是你松手的那一格**。不再有"靠近边界自动吸附"这回事：把 HUD 拖到离边 1 像素处松手，它就停在 1 像素处，可以随意细调；一路拖到边上则精确贴边，并且改窗口大小、改 GUI 缩放、换一台机器之后仍然贴在那条边上。居中的永远居中，也不会跑到屏幕外。想精确居中？点「放置」按钮。
- **元素可以一路拖进组件库下半部分**。它全程跟着指针，不会在预览区下缘被挡住——组件库比预览区更高，这一点才有意义。在库里的落点行为与从前完全一致：过了移出阈值就离开画布，没过则横坐标贴左缘、纵坐标保留你拖到的高度。
- **拖动区域的每条边都是实墙，而且墙不会在光标底下挪位**。元素拖不出屏幕左侧：往左推到极限时正好与组件库左缘齐平，不会有一小块陷在屏幕外。预览区底边在**整条宽度**上都能挡住元素；唯一能继续往下走的地方是组件库那一列，它比预览区高。沿组件库顶部上下拖不再有 1 像素阶跃，沿预览区右下角拖着走也不会再被猛地弹上/弹下到画布里。比组件库列还宽的元素下不到预览区底边以下——那里没有它容身的库列——但它照样能整块拖进库里完成移出。
- 列表里除十个实用 HUD 外还有**可拖动计分板**（默认关，与其余 HUD 元素一致）。编辑器的计分板框恒定显示代表性样张，从哪打开都能定位。例外是抽奖统计 HUD——它出厂就摆在画布上且默认显示。
- 画布**正下方**是操作区，两行：「显示」「移入/移出画布」+ 缩放滑条 / 「重置」「保存」「取消」。顶栏只剩标题与右上角那枚状态图标。
- 悬浮组件库一行，文字说明与 HUD 样张之间**空一行**，看得更清楚。从列表往外拖的时候，光标下**直接显示这个 HUD 的真实样子**，不用松手就能看出摆在那儿合不合适。

## 安装

1. 安装 **Fabric Loader 0.16.14** 并创建 **1.21.4** 版本实例。
2. 将 `NoMoreZombies-0.2.0-pre.jar` 放入你的 `mods/` 文件夹。
3. 依赖（需同时安装）：
    - **Fabric API**
    - **MaLiLib**（外部依赖，需单独安装）
    - **ModMenu**（可选，用于从 Mod 列表打开配置）

## 配置

- 从 ModMenu（NoMoreZombies > Config）打开配置，或按默认热键 **Z+X**。
- 所有功能开关**默认关闭**（Tweakeroo 风格），唯一例外是「实用 HUD 总开关」——它默认开，而抽奖统计 HUD 出厂即已放置并显示，所以新装进游戏能看见这一块。伤害飘字也是默认关。可在配置界面为任一开关绑定热键，游戏中即时切换。
- 配置文件为 `config/nomorezombies.json`（明文，可手动编辑）。
- 数据表（波次时间、首领回合、道具规律、AA 回合详情）在游戏内按 **F3+T** 热重载。
